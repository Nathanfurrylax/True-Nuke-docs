Documentation du bot

Tout ce qu’il faut savoir pour vivre avec le bot et pour le gérer.

Je suis membre du serveurComprendre le règlement à valider, les messages que le bot peut m’envoyer et mes questions courantes. Je suis admin ou modérateurInstaller, utiliser les commandes, régler le bot depuis le panel et dépanner.

Le bot en quelques mots

  • Il veille sur le règlement : les nouveaux membres qui ne l’ont pas validé reçoivent un rappel, puis sont bannis si rien ne change.
  • Il offre à l’équipe des commandes de modération : /warn, /kick, /ban, /detect, ainsi que /say, /espace et /botinfo.
  • Tous ses messages et ses délais se modifient depuis un panel web, sans toucher au code.
